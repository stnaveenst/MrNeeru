# Mr. Neeru — Static Website

A modern, responsive, dependency-light website for **Mr. Neeru Packaged Drinking Water**.

## Files

- `index.html` — website structure/content
- `styles.css` — responsive design and brand styling
- `script.js` — mobile navigation + dynamic copyright year
- `assets/mr-neeru-label.jpeg` — supplied Mr. Neeru label artwork

## Before publishing

The supplied label does not contain a complete customer-care phone number or email address, so the website uses placeholders:

- `Add your phone number here`
- `Add your email address here`

The social buttons currently point to generic Instagram/Facebook/YouTube home pages. Replace them in `index.html` with the official Mr. Neeru pages.

Search for these strings in `index.html` and update them before publishing.

## Deploy with GitHub Pages

1. Create a new GitHub repository, for example `mr-neeru-website`.
2. Upload the files and folders from this project.
3. Commit and push to the `main` branch.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`.
7. Save. GitHub Pages will publish the site.

No Node.js, Python server, database, or build step is required.
